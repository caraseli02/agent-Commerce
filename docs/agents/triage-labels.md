# Triage labels

Label vocabulary for ECAS GitHub Issues.

- `needs-triage` — new issue needs review
- `needs-info` — waiting on missing details
- `ready-for-agent` — scoped, reproducible, and ready for autonomous pickup
- `in-progress` — currently claimed by an agent
- `ready-for-human` — needs human decision or implementation
- `wontfix` — will not be addressed

## Rule

Do not create duplicate labels with slightly different names. Reuse these exact strings.
